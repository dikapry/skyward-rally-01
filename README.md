Skyward Rally — an original browser flight game. Fly a jet through four golden rally gates over stylized low-poly terrain at sunset, manage throttle, fuel and hull, then bring it home on the runway. Keyboard and mouse; runs offline from static files in `game/`.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in a desktop browser
# W/S or Up/Down: pitch · A/D or Left/Right: bank and turn · Q/E: throttle · Enter/Space: launch
```

To regenerate the hand-in artifacts locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
